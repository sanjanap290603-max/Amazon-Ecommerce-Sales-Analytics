# Amazon E-commerce Sales Analytics

## Project Overview
This project analyses Amazon e-commerce sales data to understand sales performance, order trends, product categories, and geographical distribution.

## Tools Used
- Python – Data analysis
- MySQL – SQL queries and business analysis
- Power BI – Interactive dashboard and visualisation

## Key Performance Indicators (KPIs)
- Total Sales
- Total Orders
- Total Quantity Sold
- Cancellation Rate
- Average Order Value (AOV)
- Unique Products
- Unique Categories
- Unique States

## Analysis Performed
- Monthly sales trends
- Category-wise sales
- State-wise sales
- Order status analysis
- Fulfilment-wise sales
- Top 10 products by sales
- Interactive filtering by date, category, state, and fulfilment
